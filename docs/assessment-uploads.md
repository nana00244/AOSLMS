# Teacher assessment uploads

Open **Coursework → Upload score sheet**. Choose a CSV or a single-sheet XLSX workbook, review the class, subject and student matches, and select **Save scores and update report cards**. The source format is the continuous-assessment sheet with Subject/Class and Assessment Category/Term metadata, Student Name, Admission Number and individual score columns such as `EXE1 (/15)`. Coursework grid CSV exports use this format too.

- Admission numbers match first, followed by unique normalized names within the selected class (including reordered names, punctuation and accents). Close names are suggested but require an explicit selection. Ambiguous names and duplicate target students block the upload.
- Subject matching uses curriculum names and common aliases such as English, Maths, Science and ICT. Unrecognized names require selecting a subject. Teachers can select only their assigned classes and subjects; the backend rechecks these permissions.
- Class exercises, homework, groupwork, quizzes, projects and terminal exams are supported. Blank cells/rows leave existing records unchanged; zero is a score. `[ABS]`, `[DNS]`, `[LATE]` and numeric marks with feedback tags are supported. Printed summary totals are ignored and recalculated from individual marks.
- Imports apply to the active term and academic year shown in the review. The file term must match. Repeated uploads replace existing slots rather than append duplicate assessments. Other subjects, terms and report remarks are preserved.
- The authenticated `workspace` Edge Function handles `import-scores`: it validates scope and scores, resolves student identities again, writes assignment slots and calculated report grades in one compare-and-swap transaction, and returns the committed snapshot. Conflicts and failed saves never report success.
- Report calculations retain the school's existing SBA scaling, capped at 50; exam marks scale to 50 using the source maximum. Other-term coursework is excluded. Importing only a coursework category preserves a separately entered exam grade, and vice versa.
- A database trigger updates the `workspace_revisions` counter in the same transaction. Supabase Realtime publishes only that counter; clients reload their role-scoped records through the Edge API. The private workspace document remains inaccessible to browser clients. Reconnect, focus and a 30-second fallback refresh recover missed events. Student report visibility continues to follow the existing certification rules.

Verification: `npm test` covers parsing, matching, blank/zero/feedback handling, permission rejection, duplicate detection, idempotency, report recalculation and term isolation. Set `AOS_SCORE_SAMPLE_PATH` to validate the original sample locally without committing its personal data. `node scripts/verify-with-temporary-admin.mjs --score-import` runs an isolated live browser test for teacher upload, persisted database values, subject restrictions, repeat upload, grid reload, and a second session's report update within 15 seconds. Temporary accounts and records are removed afterward.
